# Menu-Driven Calculator

## Description
A robust C++ console application that allows users to perform multiple math calculations (addition, subtraction, multiplication, division, power, and modulus) via an interactive menu loop until they choose to exit.

## How to Run
1. Open the project folder in Visual Studio[cite: 11].
2. Press Ctrl+F5 to build and run[cite: 11].
3. Select a menu option (1–7) and enter your numbers when prompted[cite: 17].

## Sample Input / Output
Input: Choice: 1, Num1: 12, Num2: 8
Output: Result: 20
